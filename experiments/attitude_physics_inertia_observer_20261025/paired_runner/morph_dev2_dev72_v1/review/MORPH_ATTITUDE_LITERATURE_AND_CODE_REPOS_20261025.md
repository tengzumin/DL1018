# 姿态 RBF 替代机制：文献与公开代码库调查（2026-10-25）

## 范围与当前候选

本报告以 2026-10-25 为资料截止日，优先核对论文原文、出版方/作者机构记录和作者或课题组维护的公开仓库。事实与项目应用推断分开写。只读了当前候选任务书、源码和公开网页；没有启动 MATLAB/Octave、Plant、闭环或训练，也没有读取 MAT/raw。本文是本次唯一新文件。

项目任务书描述的冻结候选是 C5 DSSM14/M110 位置栈，关闭姿态 RBF 输出和更新，改用解析惯量项与有界力矩残差观测器。其核心机制为：根据当前命令积分 `rho_hat`，由质量属性函数求 `Jhat/Jdothat`，以 `(Jhat-J0) alphaBS + omega×((Jhat-J0)omega) + Jdothat omega` 补偿预计的构型惯量效应；姿态事件上由角动量差分、陀螺项积分和区间平均的**广义限幅命令**形成残差，再经 0.10 s 一阶滤波、加速度等效限幅和既有 beta ramp 形成补偿。该命令在 C0 电机分配之前，代码没有把实际电机力矩当 observer 输入。候选按理想的 `rho_dot=0.05u` 模型重建构型。项目中的具体约定见[DEV72任务书](../ATTITUDE_PHYS_INERTIA_DEV72_TASKBOOK_v1_ZH.md)、[候选helper](../../../phys_attitude_replacement_candidate_v2.m)和[J0校正补充条款](../../../ATTITUDE_PHYS_OBSERVER_J0_CORRECTION_ADDENDUM_v1.2_ZH.md)。

**重要的物理解释（由上述残差定义推出）：** 该 observer 估计的是“实际力矩与输入给残差计算的命令力矩之间的合成残差”，可能同时包含风、执行器/分配误差、C0 与构型分配差异及模型误差；不能仅凭它称为风矩估计器或真实外扰分离器。候选相对主基准 B 的 DEV72 结果也是系统级比较；位置栈与姿态方案同时不同。项目任务书单列的“C5位置栈 + 原姿态RBF”控制臂才更适合回答姿态替代本身的增量效果。

## 对 frozen 候选的可证伪启示

以下均是后续离线分析或另行授权实验的**推断/建议**，不是本次新结果，也不建议在当前锁定运行中改参。

1. **把形态惯量前馈的作用与 observer 和位置栈分开。** 若该项有效，其变化应主要出现在活动臂/快速 `rho_dot` 区间；无形变的 C00 场景中，应有 `Jhat≈J0`、`Jdothat≈0`、`tau_shape≈0`。若 C00 与强 morph 场景改善相近，单靠形态前馈解释收益就不充分。candidate 对 B 的 DEV72 总差同时含位置 DSSM14 与姿态替换；归因应使用任务书中的 C5位置栈 + 原姿态RBF控制臂。
2. **把 `dhat_tau` 称为 lumped residual estimate。** 离线可用完整 Plant/allocator 日志核对它与“实际施加力矩−残差输入命令”的关系，并分别检查风矩、分配偏差与构型效能变化对残差的占比；这些真值只用于评分/诊断，绝不能进入候选在线输入。若观测主要跟随 C0/电机分配差而非外扰变化，则“风扰估计”解释被证伪。
3. **检查命令构型重建假设。** `rho_hat` 来自命令积分而非测量到的臂位置。用已有允许的离线真值审计 `rho_hat-rho_true` 随形态速度、活动拓扑及命令端点的变化；若误差在伺服滞后或饱和期间上升，`Jhat/Jdothat` 前馈依据就不够准。该项在仿真命令与构型严格一致时成立，不自动外推到硬件。
4. **按 observer 更新相位与形变窗口报告误差。** 100 Hz 更新、0.10 s 低通以及 beta ramp 都引入响应时间；统计 observer 更新后 0–0.1 s、0.1–0.3 s 和非 morph 区间的 SO(3) 误差与安全量。如果误差峰值与变形切换同步且长期未被估计压下，固定低通残差机制不足以解释快速瞬态。不得依据这些分段结果临时调当前 frozen 参数。
5. **几何控制和 INDI 是后续可比路线，不是零成本替换。** 几何控制的主要收益预期在大 yaw/大姿态误差及 SO(3) 表达；若本场景始终是小角度跟踪，它未必改善主分数。INDI 的关键可证伪条件是实际角加速度估计和力矩控制效能/执行器增量：仅用请求命令替代已施加输入会把分配误差混进闭环估计，且延迟需显式对齐。

## 结论边界

公开文献已经分别展示 SO(3)几何姿态控制、带角加速度反馈的 INDI、形态感知惯量/CoG/控制分配、observer/adaptive disturbance rejection，以及真实 morphing 飞行。因而这些机制本身不能据此宣称新颖。候选可能有价值的部分，需要由其**冻结组合在锁定同场对照下的可复核效果、因果输入边界和形态分层分析**来判断；本调查不确认候选已胜出，也不声称新颖性已成立。
