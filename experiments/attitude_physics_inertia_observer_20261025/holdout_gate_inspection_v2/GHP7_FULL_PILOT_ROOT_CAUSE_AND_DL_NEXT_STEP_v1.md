# GHP7 全量 pilot 复核与深度学习下一步

日期：2026-10-26（Asia/Shanghai）  
范围：冻结任务书 v2、release revision 7、54 次 GHP7 pilot 的完整配对评分；不读取 TEST 数据。

## 审核结论

**建议转向深度学习姿态补偿，并从部署输入中移除逐时刻的惯量重建。** 本次 pilot 的最佳配置是 C5+10：它关闭 RBF 和 observer，只保留由形态命令驱动的惯量模型前馈。因此它证明了这份仿真里模型前馈很有效，却没有证明一个不重建 `Jhat/Jdot_hat` 的学习控制器也能取得该收益。

C5+11（无 RBF、带前馈和 observer）没有胜过共享同一前馈的 RBF 对照。按冻结任务书，旧的 432-call physics/observer 批次不放行。下一阶段应另立深度学习任务书；本报告不启动训练或新的 Plant 航次。

### 机制解释

1. `C5_RBF_F` 对 `C5_RBF`：在 RBF 上加共同前馈后，三项宏平均都变好。说明这份仿真中前馈确有收益。
2. `C5_10` 对 `C5_00`：无 RBF、无 observer 时，只打开前馈，宏平均 Q0–20 从 13.850 降至 11.978 mm、Q8–12 从 19.941 降至 14.780 mm、SO(3) 从 66.580 降至 62.913 mrad；C5_10 6/6 可行。
3. `C5_11` 对匹配的 `C5_RBF_F`：前者只在 Q0–20 1/6、Q8–12 0/6、SO(3) 2/6 场更好；其三项均值也都较差。因此当前 observer 版 RBF 替代不成立。
4. `C5_11` 对 `C5_10`：加入 observer 后没有赢过任何场景的 Q0–20 或 Q8–12，SO(3) 只赢 2/6；均值与可行数也更差。当前证据不支持继续扩展这版 observer。

细分观察：C5_10 在 W00 的 3/3 场赢 B 的 Q0–20、Q8–12 和 SO(3)；W12 为 2/3、2/3、1/3。W12 的 3 场宏平均仍优于 B，但不能代表全部 W09–W14 高频工况。

几何对照按预登记规则选中 FIXED_MIN；其应用可行 5/6，有一场触发 tilt limit。FIXED_BOUND15 的 6/6 场均未通过 15 mm clearance proxy。两种配置都保留在评分中；不把几何选择当成姿态控制方法优势。

## 惯量重建是不是“作弊”

这不是直接读取 Plant 真值的 oracle：候选 helper 没有接收 Plant 的实际惯量或实际施加力矩。但它是**显式模型前馈**，而且依赖理想形态执行假设。

helper 将形态命令积分成 `rho_hat`，按 `rho_dot_hat = 0.05*u` 调用质量几何模型取得 `Jhat`、`Jdot_hat`，然后计算

`tau_shape = (Jhat-J0)*alphaBS + cross(omega,(Jhat-J0)*omega) + Jdot_hat*omega`。

因此 C5_10 的最好结果依赖可用的形态命令、准确几何质量模型和理想命令跟踪。在真实执行器有滞后、间隙或编码器误差时，命令积分不必等于真实臂长。将其称为“无模型深度学习结果”或直接当作论文主方法都不准确；更合适的用途是这轮 pilot 的物理前馈参照/诊断项。

## 现成深度学习数据能否直接复用

仓库已有 A1T/A1R 姿态训练产物与 ALL816 标注。A1T 使用 768 个 B TRAIN 场景、48 个 B VAL 场景，VAL 未使用 C5_VAL48 或 TEST；其 `X18` 配套标签是直接补偿目标 `target_raw_output_rad_s2 = C*/beta`，不是从这次 GHP7 得出的无惯量深度学习结果。该 `C*` 标注生成会读取仿真 Plant 的 `J/Jdot` 来算 `E0` 和 `G`，所以属于物理特权监督标签；即使推理时不暴露这些量，也必须明示，不能包装成纯数据标签。A1R 也有独立的目标和数据版本。

这些材料可用于追溯合法可用的 TRAIN 来源，但**不应原样复制旧的大输入、旧网络或旧 RBF 目标**：用户已要求重新设计且减少输入。正式训练前，先审计原始 B TRAIN 中有哪些实时可测信号，重新确定短小输入和目标；C5_VAL48 与 TEST 继续保持未参与训练和选模。

## 推荐的 DL 姿态替代方向

- 新建小型**因果 TCN**，输入只保留姿态误差、机体系角速度、BS 名义角加速度/力矩，以及当前形态控制命令；用时间卷积处理短历史，不手工构造 `Jhat/Jdot_hat`，不读 Plant 真值、未来值或 RBF 隐状态。输出有界的角加速度残差，再用固定名义 `J0` 转为小幅力矩修正；固定 `J0` 不随形态在线重建。
- 若运行时只有形态命令而没有臂长编码器反馈，报告中明确这是理想形态执行仿真。后续若有可部署的臂长/速率测量，可用它替换命令积分假设；不得拿仿真的 `rho_true/rhoDot_true` 当部署输入。
- 训练监督首选由合法 TRAIN 闭环日志的相邻角速度变化构造角加速度残差标签（只在离线生成标签时用后继样本；特征仍严格因果），再评估 10 ms 差分噪声与滤波滞后；该路线不需要 `Jhat/Jdot_hat`。旧 `C*` 标签或 C5_10 输出可做单独的教师消融，但都标记为物理特权监督，不作为默认训练标签；教师的物理前馈收益不得包装成神经网络独立发现。推理图不得保留 Plant 真值或逐时刻惯量恢复。
- 第一轮固定单个小网络和单个训练配置；先做 no-Plant 因果/边界/部署可用字段检查，再用 DEV 做配对筛查与全 DEV 审核。模型冻结前不读 TEST、不重新跑 B 或 C5。新候选必须同时相对 B 改善位置和姿态，并单独对原 RBF 说明替代效果。

深度学习路线有直接先例：DMRAC 报告了小型四旋翼上的深度网络姿态控制与故障/风扰飞行试验；Neural-Fly 展示了预训练表征配合低维在线适应的路线；可折叠四旋翼文献支持形态变化下姿态动力学问题的必要性。但这些来源只支撑架构选择与研究动机，**没有一篇证明本项目的主动变形四旋翼深度学习控制器已经有效**。[DMRAC（PMLR）](https://proceedings.mlr.press/v155/joshi21a.html)、[Neural-Fly 论文](https://arxiv.org/abs/2205.06908) 和 [作者代码库](https://github.com/aerorobotics/neural-fly)、[Foldable Quadrotors 姿态控制](https://arxiv.org/abs/2209.08676)。

## 下一步决定

1. 标记本次 54-call pilot 为“完整筛查已评分”，不把它写成论文达标结论。
2. 停止扩展 C5_11 observer 和本轮 physics/observer holdout。
3. 起草新的深度学习姿态替代任务书：先锁定可部署特征、标签来源和 TRAIN/DEV/TEST 边界，再决定训练及闭环航次。TEST 继续封存。
4. 以 C5_RBF 为主要替代基线、B 为系统级基线；C5_10 作为模型前馈诊断参照，不作为纯 DL 候选。
