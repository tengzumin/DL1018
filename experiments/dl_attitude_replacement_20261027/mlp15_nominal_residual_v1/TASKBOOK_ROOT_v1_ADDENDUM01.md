## Required data source

Use only the identity-locked C5 variable-morphology TRAIN_C5_24 raw trajectories enumerated in:
experiments/dl_attitude_replacement_20261026/mlp15_c5_teacher_full72_v1/MLP15_C5_TEACHER_FULL72_SOURCE_LOCK_v1.json
and cross-check source hashes/paths against the frozen training_config.json in the same study.

For each TRAIN_C5_24 raw, reconstruct the event features and the fixed-J0 residual labels from past body-rate samples, timestamps, and already-issued controller body torque. Prove each label endpoint is no later than the feature event and preserve the exact scene identity. The 13-D features must be generated by the locked candidate feature code; do not substitute the fixed-morphology B teacher dataset merely because it has a convenient TRAIN split.

C5_VAL48 may be used once for offline evaluation only. It must not influence target/input normalization, optimization, checkpoint selection, threshold choice, or code changes. Do not read TEST.

## Comparison and claim boundary

The old C5 full72 checkpoint used TRAIN_C5_24 plus C5_VAL48 for fitting, so it has no independent validation and is not a fair training-split comparator. Reuse it only as a legacy code/model reference; explicitly disclose the split difference. Do not claim a one-factor causal comparison against its metrics. This candidate's honest evidence is TRAIN fit + one-shot VAL48 offline diagnostics, followed only after root review by a separately released closed-loop screen with reused B/C5 comparators.

## Early stop

If raw identity, issued-torque source, feature/event alignment, legal-input boundary, or a usable TRAIN_C5_24 split cannot be proved from local records, stop before training and return the exact missing evidence. Do not silently substitute the B-fixed teacher dataset, any VAL rows, or TEST.
