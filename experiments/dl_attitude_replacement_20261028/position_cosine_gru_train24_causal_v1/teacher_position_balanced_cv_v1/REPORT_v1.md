# Teacher + position balanced GRU: fixed four-fold OOF

## 预定方案

- 模型：Existing ResidualGRU: GRU(14,32)->Linear(32,3), zero-initialized head, per-scene hidden reset.
- 训练：Adam，学习率 0.001，每折 300 步；随机种子 20261028 + 折序号。
- 目标：0.5 × teacher delta 训练折 RMS 归一化 MSE + 0.5 × 位置动作误差训练折 RMS 归一化 MSE；两尺度都只用该折训练场景 ready 行。
- 动作：`clip(a_C5 + clip(t/1.8, 0, 1) × clip(delta, -0.5, 0.5), -3, 3)`；X14 按训练折全时序行均值/标准差归一化。
- 每折所有留出场景整体留出；验证只作 OOF 评分。未读 VAL/TEST 原始数据，未跑 Plant，未做惯量重建。

## 局限

- 数据仅来自 TRAIN_C5_24；父级 cosine-GRU 已见过这些场景，因此不能代表完整控制器的独立泛化。
- 姿态指标是冻结状态和参考下的滤波重放，不是闭环飞行结果。
- 新变体相对前版 teacher 学生改善了位置指标，但姿态 RMSE 略差；相对普通位置残差学生，本次姿态更好、位置明显更差。
