# MLP15 姿态替代候选：闭环筛查任务书 v1

## 闭环比较与筛选

- 候选为 MLP15，冻结 59,000 步权重；位置控制沿用锁定的 C5 DSSM14，BS 姿态名义环、Plant、allocator 和执行器保持不变。MLP 是冻结的监督网络，无在线权重更新；运行时不使用姿态 RBF、惯量重建、observer 或物理前馈。
- 只运行 GHP7 原六场 ACTIVE 场景：G1/G2/G3 × W00/W12。B 与 C5_RBF 使用已有同 payload、同 R_task 的 raw；C5_10 仅作可复用诊断参照。对照身份不符时该场不得记为配对，且不得重跑、覆盖旧对照。
- 新增最多 6 个 MLP15 闭环航次。每航次单独记录启动 marker、输入/源码/模型 SHA、原始输出和完成/安全状态。TEST48 不读取、不运行。
- 六场全部完整结束、状态 STABLE、无安全停止、饱和、通用裁剪或倾角限制，且候选相对 B 的六场宏平均位置 Q 与 SO(3) RMSE 均严格改善，才晋升到 DEV72。场景逐项和 W00/W12 分组结果全部报告；任一组平均退化明显或出现异常，暂停扩展并复核。
- C5_RBF 与 C5_10 的闭环差值同时报告，但它们不替代 B 的主基线，也不单独决定是否晋升。该六场筛查不能作为论文统计结论；最终筛选仍依据完整 DEV72，TEST48 仅在 DEV 与候选冻结通过后一次性使用。

## 输入与运行前置门

- 训练/模型/normalizer 身份必须匹配 `mlp15_formal_v1/run_v1/` 的 PASS 训练配置与独立 VAL48 审计。
- MATLAB MLP15 前向 parity 最大绝对误差不超过 `1e-5 rad/s^2`；源树静态审计、无 Plant 冒烟和身份绑定全部通过后才允许闭环调用。
- 新 runner 与所有输出位于本目录内的独立 MLP15 版本目录；不得改写 TCN 源树、历史 pilot、MAT、模型、缓存或账本。
- 每个候选 run 启动前重新核对当前 MATLAB/Plant 进程，不终止或打断现有实验；失败航次保留且计入六航次额度，不通过同场重跑改写结果。
