# 有限窗口教师目标别名：结构可能性说明

2026-10-27 主审推导，依据已复现的rbf_mimo_update。不是已观测闭环根因、不是GRU必胜证明、不是完整稳定性证明。

未发生逐元素投影时，每一输出列的更新为 W_next=(1−dt*sigma_w) W−dt*Phi*gamma*sat(surface)。若两段历史在之后N次更新具有相同输入、学习surface及dt，差分状态满足 deltaW_N=(1−dt*sigma_w)^N deltaW_0。

已核原C5参数dt=.01s、sigma_w=[.11,.12,.20]。15次相同更新后的差分保留系数为[.9836264464,.9821504166,.9704163817]，即约97–98%。更新前输出在第15事件所保留的前缀状态更多，而非更少。可选足够小的deltaW使该构造不触发权重/输出裁剪，并使deltaW.T*Phi不为零。

因此在一般控制器输入历史上，同样的有限后缀可对应不同teacher隐藏权重及输出；每窗口零初态的确定性学生不能对这些历史同时精确匹配。这只是一般输入历史上的结构可能性，不证明本数据集中已有完全相同窗口对，也未证明这些构造均为物理闭环可达状态；不把它当训练误差不可约的已证数值下界。

它支持检验持续状态协议的动机：旧姿态screen只覆盖15event上下文，不能据其排序否定长记忆模型。新GRU32不扩输入/网络，先以同一开发序列数据检验跨场内hidden；性能仍须独立实际闭环确认，最终B/C5标准不变。
