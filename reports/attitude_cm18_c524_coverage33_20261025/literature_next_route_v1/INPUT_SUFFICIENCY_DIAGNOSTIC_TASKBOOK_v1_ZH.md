# 输入充分性诊断任务书 v1（待审批草案）

**状态：草案；待主审审批；未执行。** 本文件只定义离线诊断，不构成执行授权，也不构成新增姿态控制器方案。它依据现有 DEV 证据作路线准备，不是独立验证。范围限定为现有 TRAIN33 与 DEV15 缓存；TEST、历史闭环结果和其他原始数据均冻结。

## 目的与边界

已有证据显示：C5_24 的 12 场筛查中 Q/SO(3) 姿态候选各胜 2、负 10；C5_COVERAGE33 的 15 场 DEV 中，位置 Q 胜 3/15，姿态环胜 1/15。静态 CM18 的 TRAIN/DEV NRMSE 为约 0.0153/0.2671（约 17.46 倍差距）；首次形变事件的 teacher-state 映射误差已明显。现有审计支持“先查现有输入是否带来场景外预测信息”的优先级，但不足以证明缺失输入、模型容量或标签坐标中的任何一个是根因。见 [C5_24 结果](../../attitude_cm18_c524_screen12_20261025/C524_SCREEN12_RESULT_v1.md)、[C5_24 根因审查](../../attitude_cm18_c524_screen12_20261025/C524_ROOT_CAUSE_DECISION_v1_ZH.md)、[C5_COVERAGE33 闭环结果](../C5_COVERAGE33_15SCENE_CLOSED_LOOP_RESULT_v1_ZH.md)、[覆盖根因诊断](../C5_COVERAGE33_ROOT_CAUSE_DIAGNOSIS_v1_ZH.md) 和 [拟合泛化报告](../fit_generalization_v1/FIT_GENERALIZATION_REPORT_v1_ZH.md)。

本诊断只回答：在既有事件标签上，CM18 的哪些**现有输入组**对按场景留出的预测误差有增量；移除某组后，误差如何变化。它不证明物理因果充分性，不预测闭环胜率，不选定最终网络，也不授权接续训练或飞行验证。

## 数据、标签与因果时序约束

仅允许读取已存在的 TRAIN33/DEV15 事件缓存及其必要索引和元数据：TRAIN 每场现有 400 个样本行（原采样行序 0、5、…、1995，共 13,200 行），DEV 每场 1,999 个事件（共 29,985 个查询）。不得重新生成缓存。TEST 不得枚举内容、读取、哈希或纳入统计；所有历史闭环结果只作冻结背景，不得因本诊断改写。

标签固定为现有同事件的 `Cstar/beta` 向量；标签轴归一化使用冻结的 TRAIN 轴尺度。输入固定取同事件 X18，通道语义为：`omega_B(3)`、`alpha_BS(3)`、`thrust/mass(1)`、当前 `u(4)`、仅使用过去积分的 `z(4)`、上一完整区间的平均力矩 `a(3)`。不得使用目标本身、未来行、未来窗口、未来力矩、TEST、风场真值、形变真值、相位编码或任何由标签反推的量。相位/形变事件只允许按已有元数据分层汇报，不作为特征；不得跨相位借邻居补足支持数。具体列顺序和事件对齐必须与冻结的 CM18 源码、manifest、row map 一致。

## 预注册比较

设置 7 个输入组：`G0` 为完整 X18；另设六个逐组留一消融：`G−omega_B`、`G−alpha_BS`、`G−thrust/mass`、`G−u`、`G−z`、`G−a`。对每组运行同一确定性 5-NN **诊断估计器**：输入按冻结 TRAIN normalizer 的对应维度标准化，距离为保留维度的均方根欧氏距离；每个来源场景只取最近一行，再从不同来源场景取 5 个邻居，按场景等权平均其标签。完全相同的距离按冻结事件行序打破平局。此方法无梯度、无拟合步骤、不调用 checkpoint、不改变模型；TRAIN 缓存只作为检索参考集。它是有限样本的输入信息探针，不能当作 CM18 的替代模型或闭环候选。

`k=5`、每场只取一个邻居、RMS 距离、标签平均方式均为拟议的诊断协议，**需主审在执行前确认**。不把由 `u,z` 理想化推导出的 `rho/rhoDot/phase` 当作独立新输入，也不加入新特征；诊断结果只对应以上六组消融。

比较按场景阻断，禁止随机行拆分：

- TRAIN 稳健性：33 折 leave-one-scene-out；每折只用其余 32 个 TRAIN 场景作邻居库，逐场计算误差。
- DEV 主评估：每次只用全部 TRAIN33 作邻居库，15 个 DEV 场景始终留出；不以 DEV 调参或选择邻居数。
- 对每组计算每场三轴归一化向量 RMSE、场景宏平均，以及配对差 `Δ_g = E(G−g) − E(G0)`（正值表示移除组 g 后误差变大）；同时列出 15 个 DEV 场景的逐场误差和胜/负/平。TRAIN 与 DEV 分开报告，不合并样本数造显著性。
- 可按已有 phase/首次形变事件标签提供分层描述。某层若不足 5 个不同 TRAIN 支持场景，则标为“支持不足/不可比较”，不得跨层回退；`5` 的支持门槛需主审确认。

**统计判定门槛目前留空，必须由主审在批准时预先填写。** 现有证据不能支持某个“最小有意义 RMSE 变化”、DEV 场景胜场数、置信区间排除零、TRAIN/DEV 一致性比例或分层最低支持数作为过关标准。本稿不继承旧辨识任务书的 20%、10/15 或 12/15 阈值。建议报告逐场配对值，并可附按场景重采样的区间作描述；区间置信水平、重采样次数及是否参与门槛判断也需主审指定。未填门槛时，只能形成描述性结果，不得据此宣称某组可删、诊断通过或开启下一阶段。
