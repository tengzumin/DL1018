# 父审：DL1018 corrected14 第一阶段根因结论

日期：2026-10-22（北京时间）。本文件取代本目录早期的 `PARENT_SOURCE_REVIEW_ZH.md` 初稿；初稿曾把未调用的 `_current` helper 当作运行实现，并在逐场配置和 raw 复算完成前提出了未经验证的解释。当前根因判断以本报告及其引用的机制、历史、理论审查为准。

## 父审决定

**继续第一轮最小因果筛查的隔离入口搭建；暂不启动训练、Plant、闭环航次或 TEST。** 现有证据没有找到 corrected DSSM14 当前运行链中的监督标签、PCF、Head 更新符号/时序或控制器应用实现错误。DSSM14 全72场虽有 4.671 mm 平均位置 Q 改善，但只有46/72场胜 B，低于62场门槛；高频 W09–W14 与无风 W15 也均未满足组均值验收，故 TEST 继续封存。

本轮唯一优先假设为：**高频场景下，在线位置 Head 更新与当前 dAtt 较大的轨迹发生动态反馈交互，可能加重 Z 轴闭环误差；同一状态上的监督残差改善不能排除此机制。** 这是待证伪假设，不是根因定论。计划用冻结 W0、只关闭在线更新的单因素筛查来区分；保留 Head 输出、FEATURE/G12/R32、PCF、X14、物理 Plant、执行器、C0/J0 和 B 姿态闭环。执行者目前只搭运行入口和配置检查；父模型完成代码审核并冻结任务书之前不得发起航次。

## 当前量化结论

- 从72个当前 DSSM 原始 MAT 和72个当前 B 原始 MAT 分别独立重算，raw SHA 与冻结配对表身份匹配，读前/读后不变，144/144个 Q 在 `1e-12 m` 容差内一致。独立重算的 scene-macro Q：B `0.017058080675 m`，DSSM14 `0.012387217899 m`，差 `−0.004670862776 m`；DSSM14 46胜/26负/0平。
- W00–W08：38/38胜，DSSM14 平均 Q `0.013969646015 m`，比 B 低 `9.245 mm`。W09–W14：5/28胜，平均 Q 高 `0.5255 mm`；W15：3/6胜，平均 Q 高 `0.0505 mm`。W15 是小的形式门槛失败，但按预登记微小收益敏感性单独报告；没有据此放宽门槛。当前共2场虽获胜但改善小于0.5 mm，0.1 mm内的改善为0场。
- 父审按配对原始位置误差独立复算三轴与时间段：高频组 candidate−B 的全程轴 RMSE 为 X `+0.064 mm`、Y `−0.338 mm`、Z `+2.274 mm`；Z 是主要可见退步轴。W15 的 3D Q差仅 `+0.050 mm`，全程轴差 X `+0.501`、Y `−0.434`、Z `+0.095 mm`，其中较大的差异集中在 `[0,5)` 的 X/Y，不能把 W15 归因于 Z。时间段固定使用 `[0,5)` 与 `[5,20)` 半开区间。
- 全72同状态重放复核：标签分解闭合最大误差 `3.03e−15 m/s²`；在线权重更新重放最大误差 `2.22e−16`；PCF eta 递推、采样对齐和应用映射均达双精度量级。W09–W14 的 Z 轴目标残差 RMS 从同状态 online-before `0.089609` 降到 online-after `0.089490 m/s²`；更新前后的小幅改善方向与“在线更新使同态目标拟合变差”相反。闭环 Z 轴退步不能由这一个固定状态误差解释，也不能由其排除在线更新造成的动态副作用。
- W09–W14 的 dAtt 向量 RMS 较 W00–W08、W15 高，且现有探索性按场统计与 Q差呈正相关；但物理分解尚未按轴和时间段拆分，样本混合闭环状态，该相关仅作提出假设的线索，不作因果证据。全场表也显示 W15 低风下主要分量是 dAtt，但其聚合 Q miss 很小。

## 历史成功如何产生、优势在哪些条件下不再成立

旧 G12/R32 的 `OLD_G12_R32` 是 DL1009 commit `3671d2d212af927abdb6d9149a1b249c372ac55e` 的旧 `N_KAN` 完整迁移包，包含当时的 normalizer 和 W0；它在8个 DEV FIG8 场景中7/8胜 B，8场平均 Q `18.439 mm` 对 `20.805 mm`。教师复用阶段的旧 DSSM14结果另为6场 TRAIN筛选（`15.389 mm` 对 `20.357 mm`），也不是盲测。两项成功都只支持其当时所选模型包在窄场景上的优势。

当前 corrected DSSM14 是 seed `2026102001`、60,000 step 的新模型，训练数据和原始运行均不同；当前验证覆盖 VAL48+DEV24、FIG8/HELIX/SQUARE 与完整 W00–W15，而旧 G12 成功只覆盖8场 FIG8。与旧 G12 重叠的8场，B 的位置 Q 全部变化，绝对差约 `2.81–7.85 mm`；旧历史 replay 的72行与当前 pair 虽按场景/contract标签对得上，候选 raw SHA 却0/72一致。故旧成功不能直接移植成当前结论，也不能用跨包差值归因于某个网络组件。当前12 mm级宏平均相对 B 的优势主要由低/中风38场的大改善支撑，到了 W09–W14 发生反转，W15仅有微小净反转；**目前没有证据把优势丢失定位到具体代码步骤。**

## 实现错误与实验条件改变

已确认并修正的历史实现问题：旧 FIG8 参考生成的 Y/Z 加速度二阶项漏乘因子2；同条件8场修复配对中，NEW KAN 相对 B 的差距由 `+3.313 mm` 缩至 `+0.347 mm`，但修复后仍未战胜 B。历史审查还发现 KAN 分支 `P_NEW` 没有应用的 dispatch 缺陷，其对旧/新汇总胜负的定量影响尚未隔离。两者都不能解释当前 DSSM14 高频 Z 退步。

当前 corrected DSSM14实际调用的是隔离 runtime 的 `position_stage1_model_forward_v2.m`，而不是隔离目录 `_current` 或仓库根目录同名模型函数。配对模型绑定、72份 `run_start`、raw中的实际 gamma/kappa/head/PCF flags 和输入身份均已核对。训练包、raw、场景覆盖和部分 B 输入发生变化属于实验条件变化，不能统称为代码 bug。此前 aggregate model-array SHA 的两种格式已逐字段核对为元数据键存储口径不同，不构成模型权重混用。

## 理论与论文证据门槛

现有源码支持的性质是：Head输出限幅、逐项权重盒投影、PCF eta在输入有界时的条件界，以及理想连续反步外环在有界总残差下的条件 ISS/UUB 误差界。现有分析没有证明 eta 输入的统一界、实际闭环不变域、投影 Euler 离散余项后的负漂移，或包含 Plant、1 kHz PCF、100 Hz 更新/ZOH、姿态和执行器饱和的实际系统 ISS/UUB。因此当前新理论门槛**不通过**；投影有界不等于闭环稳定，也不能将有限仿真当作证明。应继续寻找能与实际离散部署逐项对应的理论结果；如果假设和数值界无法审计，报告为理论缺口，不宣称理论贡献。

相关原始文献对照及全文访问边界见 [theory_and_literature.md](theory_and_literature.md)。历史成功与条件差异见 [historical_lineage_review.md](historical_lineage_review.md)。72场重放、方程、同状态分析和其限制见 [mechanism_audit.md](mechanism_audit.md)。父审重新核对发现机制报告中的两处来源哈希抄录错误（tail21 RAW_INDEX截断、binding SHA中`B8DD`误写），已订正；其重放数据/表格未改变。
