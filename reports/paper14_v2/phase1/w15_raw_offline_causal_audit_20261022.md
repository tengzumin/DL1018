# W15 原始记录逐变量离线因果审计

日期：2026-10-22。用途：在已完成的 W15 三任务记录上定位早期控制链分叉，并区分实现错误、候选配置变化与尚未解释的性能差异。全程只读，不启动 MATLAB、Plant、训练、预检或新航次，不访问 TEST。

## 审核结论

**没有发现可确认的实现错误，但 20 ms 微小分叉的来源仍未定性。** B 与 DSSM 候选在 20 ms 的首个可测差异出现在位置命令力：日志中的 B 补偿字段有约 \(5.2\times10^{-9}\)、\(5.8\times10^{-9}\)、\(5.9\times10^{-8}\) N 的微小非零值，候选在 Head readiness 前为零。现有记录没有完整运行 cfg；源码审计又指出，正式 B2-BS 路径在没有额外补偿时不应启用位置 RBF。因此这些 MAT 数值不能单独证明旧 RBF 路径在运行，也不能判为数值残差或实现错误。当前没有证据显示该微小分叉解释了毫米级组间差距；但仅凭幅值也不能排除长时闭环累积。PCF-on 与 R3 的后续首个动态差异符合预定 z 轴 eta mask 改动，属于候选配置变化，尚未证明它改善或造成总体 W15 表现。W15 相对 B 的主要误差来源仍未定位。

## 身份、字段与时序

审计仅读取已登记身份表中三场各自的 B、PCF-on、R3 XY 共九个 raw_run.mat。主会话逐一重算 SHA256，均匹配 w15_offline_diagnosis_20261022.md 的对应身份。没有读取 PCF-off 文件。MAT 为 v7.3/HDF5；MATLAB 语义下每场有 20,001 个状态时点和 20,000 个控制转换。time 是状态时钟，transition_time 是转换左端点；因此 0.020 s 的控制请求基于 20 ms 状态，在推进到 21 ms 前记录。

MAT 日志字段覆盖完整状态、参考位置/速度/加速度/yaw、位置名义力与补偿力、Head/PCF 状态、姿态目标、滤波请求和输出、姿态力矩、广义请求/实现量及电机量。单位按字段名并与允许审计的源码交叉核对：位置 m、速度 m/s、加速度 m/s²、位置力 N、力矩 N·m、欧拉角 rad。MAT 本身未提供独立单位元数据。

## B 与候选的首个分叉

三对记录的初态、完整参考和 20 ms 状态完全相同。按字段绝对差大于 \(10^{-12}\) 检查，20 ms 首个位置请求差异是 position_commanded_force_N；随后 requested_generalized、raw_outer_attitude 与 command_filter_target_euler 也已不同。首个完整状态差异在 21 ms，均为极小机体角速度差；位置名义加速度到 22–28 ms 才出现差异，晚于控制请求和状态分叉。

| W15 场景 | 20 ms 位置命令力最大分量差 | 20 ms 广义请求最大力矩差 | 21 ms 首个状态差异 |
|---|---:|---:|---|
| HELIX / T1_C08 | \(5.19\times10^{-9}\) N | \(8.04\times10^{-10}\) N·m | 机体 p 角速度，\(2.47\times10^{-10}\) rad/s |
| FIG8 / T2_C05 | \(5.77\times10^{-9}\) N | \(8.94\times10^{-10}\) N·m | 机体 p 角速度，\(2.74\times10^{-10}\) rad/s |
| SQUARE / T3_C02 | \(5.86\times10^{-8}\) N | \(9.07\times10^{-9}\) N·m | 机体 q 角速度，\(2.79\times10^{-9}\) rad/s |

源码 position_bs_step 采用 commandedForce = nominalForce − residualForce。B 日志的 position_rbf_compensation_force_N / position_compensation_applied_force_N 在该时点为微小非零值，候选的位置 Head 仍未达到 32 个历史事件的 readiness，故候选 held force 为零；候选到 0.320 s 才首次更新，0.330 s 才有新 Head 输出。这个时序解释了**观测到的最早字段差异**。但源码审计指出，B2-BS 在正式 Full/SPLIT 路径中没有位置 RBF 输出调度；在没有额外位置补偿的正式配置下其位置残差力应为零。由于部分 B/R3 MAT 缺少完整数值 cfg，当前不能确定 B 日志微小非零值来自额外补偿配置、浮点残差还是运行身份/配置差异。因此把整体的 B 与 DSSM 位置补偿机制视为不同是合理的，但**不能将这个特定早期差值定性为已确认的预期 RBF 输出或代码缺陷**。它是一个很小的首分叉信号；目前没有证据表明它导致后续性能差，但也不能仅凭幅值排除长期闭环放大。
## PCF-on 与 R3 的首个分叉

三场在 0.320 s 的同一 Head 事件上，位置特征、更新前权重及输出一致；R3 将 eta mask 从 PCF-on 的三轴改为 [1,1,0] 后，首个更新坐标/权重差异只在 Z。Z 轴 Head 输出在 0.330 s 首次分叉，完整状态在 0.331 s 首次分叉。依照 position_stage1_update_head_pcf_v3_5 的输出先于更新顺序，对记录输入离线重算权重更新，与 MAT 中更新后权重一致；用更新权重重算 0.330 s 输出，误差约 \(10^{-17}\)。这验证 mask 按设定进入控制链，**不构成其对闭环误差有利的因果证明**。

在这三场、固定 12 场筛查中的 W15 子组，R3 的场景宏平均 Q 为 8.977088 mm，B 为 8.628703 mm（R3 高 0.348385 mm）；PCF-on 为 8.984548 mm，R3 相对 PCF-on 仅低 0.007459 mm。R3 与 PCF-on 的 X RMSE 分别为 6.836015 与 6.837031 mm，都比 B 的 5.738941 mm 高约 1.097 mm。故 R3 的 z-mask 几乎未动 X 差距，筛查门 G4 仍失败。此处仅为三场固定筛查，不代表全六场 W15 或独立测试结论。

## 代码审查结论与残余风险

- position_bs_step.m:17-27 的误差、名义加速度和力级补偿方向与日志单位/符号一致。
- position_stage1_update_head.m:8-15 与 position_stage1_update_head_pcf_v3_5.m:8-15 显示事件输出使用更新前权重，随后才进行 eta 协调更新、泄漏与盒投影；与 0.320→0.330 s 日志一致。
- position_filter_realization_pcf_step_v3_5.m:13-21 中 PCF 重构量是按推力和滤波姿态得到的加速度与请求加速度之差，不是实际 Plant 加速度误差。command_filter_step.m:14-24、vehicle_derivative.m:31-38 与 rk4_vehicle_step.m:13-17 显示滤波/姿态/电机限幅之后的真实闭环还包含多级动力学与积分。
- 不是所有 MAT 都嵌入完整数值 cfg：B HELIX、B SQUARE 与三份 R3 记录缺少该结构；R3 runIdentity 也不含全部运行参数。因而本次没有声称所有配对的控制/Plant 参数、来源哈希与电机分配链逐项一致，也没有把任何字段差异外推为唯一根因。
- 审查范围内未发现可确认的计算方向错误或其他可行动代码缺陷；但 B 记录中的微小补偿字段与 B2-BS 源码路径之间存在待身份核对的差异。无法解释的部分仍是 PCF-on 与 B 在共同初态后的整条控制链差异如何累计为 X 轴和 W15 Q 差距；现有轨迹对比不是固定闭环状态的组件反事实。

## 主审决定

研发轮次已达 3/3，R3 固定筛查的 W15 子门失败，72 场扩展未授权；完整部署理论门未通过。**停止新增闭环运行，TEST48 继续封存，不宣称论文证据包达标。** 若未来另行批准新的预算周期，第一项应是先审计完整配置/源码身份，再对同一 W15 状态做离线逐级重放（位置名义力与补偿 → 姿态/推力目标 → 命令滤波 → 姿态力矩 → 广义量与电机请求）；只有离线链路能无歧义复建，才编制新的单因素任务书。真实 Plant 量只用于离线诊断，不进入部署输入。

范围与代理边界：离线变量审计按任务书指定的九个 W15 MAT 与列明源码执行；未扩大目录范围。该代理报告字段重算结果，主会话交叉核对源码方程、已有身份表与指标；分析模型/速度档位无法由工具独立证明。本审计不读取新数据、不运行实验、不修改原始产物。
