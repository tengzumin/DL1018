# 固定状态补偿映射的局部增益关系

2026-10-25，Root。下面是从已核验部署方程得到的局部代数推导，不是已观测到的故障结论，不放行额外实验或结构修改。

固定某一记录状态的真实形态、惯量/分配矩阵、角速度、风矩、推力，以及过去输入窗口。令名义 BS 角加速度为 `a`，名义力矩为 `tauBS=J0*a+cross(omega,J0*omega)+Jdot0*omega`。在当前 allocator 对所考察局部动作线性且无广义裁剪/电机饱和的区域，已审物理式可写为

```text
alphaTrue = G*a + b - G*c
E0        = (G-I)*a + b
cStar     = G^(-1)*E0 = (I-G^(-1))*a + G^(-1)*b
```

这里假定 `G` 可逆；`b` 在上述固定条件下不随 `a` 改变，`c` 是 beta 后的实际补偿。因此理想施加补偿对名义角加速度的局部导数为

```text
dcStar/da = I-G^(-1)
d(alphaTrue)/da = G*(I-dcStar/da) = I
```

当前网络的 raw 物理输出为 `y=f(X18)`，部署动作 `c=beta*clip(y)`。固定 beta，且不在限幅拐点时，令 `Dclip` 为逐轴未限幅取1、严格限幅取0的对角导数，则

```text
J_y_a       = d f / d X18[alphaBS]
J_applied_a = beta * Dclip * J_y_a
J_response  = G * (I-J_applied_a)
```

无约束理想局部参照是 `J_response=I`；当 `beta>0` 时，raw 理想目标的导数为 `(I-G^(-1))/beta`。这表明瞬时输出误差与局部输入增益是不同量，某点预测误差较小不保证邻域反馈响应准确。它只提供一个可检验关系，不证明网络增益已经异常，也不证明它导致已有姿态退化。

适用限制：限幅拐点不可直接套可微式；任意动作引起 allocator 活跃约束变化时须回到完整分配器。这里固定了 omega、推力、形态和过去请求力矩窗口，仅给名义加速度输入的条件一步响应；真实闭环中这些量及历史会联动，网络对过去请求力矩的依赖也引入动态通路。不能将某个局部 Jacobian 的特征值直接当作整个离散闭环的稳定性判据，更不能由有限记录证明全局稳定。
