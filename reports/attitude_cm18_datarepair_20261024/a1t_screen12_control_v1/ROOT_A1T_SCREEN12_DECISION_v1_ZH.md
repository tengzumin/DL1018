# A1T 十二场闭环审核：未通过，转离线机制定位

决定：冻结并保留 A1T 这次真实训练、模型和全部十二场产物，不扩大 A1T 到开发全场或 TEST。下一步只实施已审核的同状态误差分解，区分网络逼近、输出可达性和 100 Hz 保持；本决定不授权新结构、调参或训练。

十二场均完成 20 s、20,000 个物理步及 1,999 次模型事件，逐场原始记录审计 PASS。RBF 输出/更新和旧融合/head 路径均未启用；控制器配置、物理场景、位置环与 A1R/C5 对齐。未发生执行器饱和或安全停止。完整四方法表已生成，Root 从 CSV 独立复算全部分组，并逐场交叉核对 audit 的全时域、前期、后期指标，结果一致。这里的 PASS 表示运行和统计有效，不是性能通过。

三个 C00 场的零形态基底使 A1R/A1T 输出均为零，两者闭环一致；与 RBF 的差异很小。T1/C05/W06 对 RBF 的差也小，但相对 A1R 的退化较大，不能忽略。T1/C15/W14 的确改善，但不足以代表全部高频。偏航补偿限幅计数为 T1/C15/W14 的 35 次、T1/C05/W06 的 163 次、T3/C15/W14 的 71 次；不得由计数直接断言限幅是根因。

四十八场同记录状态回放中 A1T 43/48 场的瞬时三轴角加速度误差优于 RBF；本次闭环只有 6/12 场姿态胜出，说明该离线代理指标不能代替闭环验收。两套场景集合不同，不能把胜率之差解释成配对统计或量化的因果效应。A1T 相对 A1R 同时改变了直接补偿标签和由标签拟合的 target-axis RMS，故不能将本次退化单独归因于标签公式。roll/pitch RMS 从约 8.66 改为 8.71 rad/s²，yaw 从 0.55659 改为 0.61258 rad/s²；输入 normalizer、初始权重、训练种子和步数保持固定。

当前关键控制路径的单位、符号、模型前向、过去输入窗口、事件时序、限幅、beta、保持及力矩减法均已核验，未发现足以解释这些结果的实现错误。仍需离线机制证据判断模型近似及保持/可达性影响；不把未发现错误等同于证明全部源码无错。
