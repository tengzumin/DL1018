# C1 TRAIN 标量校准独立复核

## 结论

**TRAIN 校准算法与冻结产物通过本阶段审核。**这只确认 `c*=0.2802979648061464` 是按预登记 TRAIN 目标计算出的单参数经验最小最大解，并且数据覆盖和解析候选记录相符；不构成闭环放行、泛化结论或 Q 改善保证。后续原 R2 ON runner 的单因素源码核验仍需单独通过。

## 核验结果

目标定义自洽：每个 run 先用原相位权重归一化 `q`，以同端点的 raw、未裁剪冻结先验输出 `p` 和 cache float32 标签 `y` 计算 `E_y`、`A`、`B`，故

```text
E_q ||c p-y||² / E_y = A c² - 2 B c + 1.
```

每个风组先对 run 的 `A/B` 作等权平均，因此组风险就是“run 等权、run 内原相位权重”的相对平方误差。该对象不是全端点等权的总体物理误差，且使用的是 raw prior，不是部署时经过 beta、clip 和在线更新后的输出。

我从已冻结的 run/group CSV 独立复算覆盖数和解析候选：1536 个唯一 run、每个 394 个端点，共 605184；三组分别为 864/576/96 个 run。`q_sum` 最大偏差为 `2.22e-16`，各组最小 `E_y` 为 W00_W08 `0.1980323`、W09_W14 `0.1932602`、W15 `0.00239922`。由三组系数得到有效候选 `0`、`1`、三个组驻点中落在 `[0,1]` 的点及组间交点；最优候选是 W15 驻点 `c=0.2802979648061464`，最坏组风险 `0.7591886944545816`。这些数值与 JSON 记录一致。候选集对区间上的有限个凸二次函数的上包络是完备的：内部光滑极小点在活动二次函数的驻点，非光滑极小点在函数交点；端点另行包含。相同/平行函数的退化情况由端点及零点覆盖，`1e-12` 平局规则也已明确记录。

两项 TRAIN 门均通过：`1-c*=0.7197020`；最坏组相对风险从 `c=1` 的 `2.3467936` 降至 `0.7591887`，差 `1.5876050`，超过预设 `0.01` 门限。逐组结果揭示了取舍：

| 风组 | `c=1` 风险 | `c*` 风险 | 变化 |
|---|---:|---:|---:|
| W00_W08 | 0.143829 | 0.592183 | 变差 0.448353 |
| W09_W14 | 0.211415 | 0.617647 | 变差 0.406232 |
| W15 | 2.346794 | 0.759189 | 改善 1.587605 |

所以这个解主要牺牲低风及 W09_W14 的先验拟合来压低 W15 的最坏相对误差。W15 最小 `E_y` 明显更小；由于预登记目标先按每个 run 的 `E_y` 归一、再在组内 run 等权，低标签能量 run 的绝对误差会被相对化放大。这是已声明目标的结果，不应把 `c*` 解读为 fleet-wide 绝对误差最优。运行/端点也不等同于独立场景样本，不能据此给出抽样显著性。

产物记录的脚本 SHA 为 `c5f25a00…e04d156f`，重放 helper SHA 为 `9e6d3a43…ad9a5`；RUNS、TRAIN index、phase state、模型源及两个系数 CSV 均有固定 SHA。结果记录 TRAIN-only 1536/605184、optimizer/Plant/GPU 为 0、未访问 TEST；state 与结果/CSV SHA 相互绑定。本审核只读派生 CSV/JSON 与源码，未重读 MAT，也未运行拟合。

## 适用边界

`c*` 是一次使用 TRAIN 标签完成的标量校准拟合，并非零学习；其门限在相同 TRAIN 目标上判断，不能当独立验证。目标也没有建模 FEATURE head 的 beta、clip、在线更新/泄漏、位置控制闭环或 Q。因此，即使 TRAIN 门通过，也只支持继续审核预先固定的配对闭环筛查，不证明闭环会改善。后续实验必须在同一原 R2 ON 源和同一 PCF 设置下比较 `c=1` 与 `c=c*`，不能把 R3 的 XY mask 混进比较；验证所有物理安全与评分门后再讨论结论。
