# ROOT 动态机制筛查补记

实际执行了三个C15场景、两种闭环的5–15s时间谱诊断（仅描述，不作因果证明）。T1/T3的CM18 yaw补偿主峰在所选(.25,40)Hz窗口内约3.66Hz，原RBF补偿主峰在窗口低端约.488Hz；yaw跟踪误差主要低频。改善的T2_C15_W09也有约3.17Hz补偿峰。因此“补偿变大/变快”与“局部Jacobian范数>1”均不能单独识别失败：改善对照也有这些特征。

当前证据不足以把未逆动作映射、100Hz保持、过去力矩反馈、训练覆盖任一项定为唯一根因。已要求执行者同时给出有效角加速度映射 G=Jtrue^-1*S*Ctrue*C0^-1*B*J0，区分它与单纯分配矩阵torque子块；对同一记录状态做fresh/held/zero及合适目标对照，并保留带符号均值以免RMS掩盖慢偏置。

另一方面独立执行者核验TRAIN旧B与当前C5外生scene数组、参考导数、风、形态命令/真值、cfg与滤波/控制器参数。该核对允许证明实验条件改变，不把状态误差差异当作外生场景差异。未放行新Plant、重训、完整72或TEST。
