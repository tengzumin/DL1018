# yaw 理想补偿对 BS 横向加速度输入的结构关系

该结论针对代码中的平面四臂模型，以及固定状态、固定形态/形态速度、推力与风的同状态线性映射；它只约束理想 yaw 补偿分量，不是闭环结论。

`default_config.m:24` 将四臂角设为 `pi/4 + (0:3)*pi/2`，`arm_directions.m:17` 给出方向 `[cos(theta); sin(theta); 0]`。`distributed_mass_properties.m:33-52` 用这些方向构造臂、旋翼、舵机的位置；`:80-118` 将局部惯量绕 z 旋转并累加，`:144-149` 用平行轴项 `(r'r)I-rr'` 平移到总 CoG，`:170-175` 的姿态旋转也只绕 z。所有这些位置的 z 分量为零，旋转后的局部惯量 xz、yz 分量为零，故总惯量为

`J = [[Jxx,Jxy,0],[Jxy,Jyy,0],[0,0,Jzz]]`。

名义惯量 `J0` 同样来自平面四臂模型，因此也有 `J0_xz=J0_yz=0`。`allocation_matrix.m:13-20` 中的推力首行 `kf*[1,1,1,1]` 与偏航末行 `km*[1,-1,1,-1]` 不依赖机臂几何；真实与名义分配矩阵 `C`、`C0` 使用相同的旋翼常数和旋向，所以在 wrench 顺序 `[F,Mx,My,Mz]` 下，`e_4' C C0^{-1}=e_4'`，其中 `e_4'=[0,0,0,1]`。滚转/俯仰行仍会依赖真实形态的力臂。

令 `S=[0,I3]` 选取力矩行，`G=J^{-1} S C C0^{-1} [0;J0]` 表示名义角加速度补偿坐标到真实角加速度的局部映射（与 `ROOT_SAME_STATE_ACTION_DERIVATION_v1_ZH.md:5-13` 的同状态线性关系一致）。由上面的结构，`G` 的 yaw 行为

`G(3,:) = [0, 0, J0_zz/J_zz]`。

在 `G` 可逆的条件下，固定状态的无约束理想动作 `c* = G^{-1} E0` 满足：`BS` 角加速度经名义力矩进入物理角加速度的导数为 `G`，而 `E0=alpha_physical-alpha_BS`，所以 `dE0/dalpha_BS=G-I`。因此

`d c*/d alpha_BS = G^{-1}(G-I)=I-G^{-1}`，

`d c*_yaw/d alpha_BS_x = d c*_yaw/d alpha_BS_y = 0`。

这个零偏导只说明固定同一记录状态和外部量时，理想 yaw 补偿分量不需要依赖当前 BS 横向角加速度；它不说明理想滚转/俯仰分量也不依赖这些输入，也不说明模型跨轴依赖必然导致闭环退化。施加 yaw 补偿仍可能经 `G(roll,yaw)` 或 `G(pitch,yaw)` 改变滚转/俯仰误差。若触发输出裁剪、分配裁剪、电机动态或其他非线性，必须按实际分配器/执行器重算，不能把无约束 `G` 公式当作其替代。

四个固定场景的离线 mask 结果中，yaw 物理误差 RMS 都下降，但其他轴变化不一致；扩展批次还出现 T3_C05_W02 的 yaw RMS 上升。因此这里只保留结构上的零偏导命题和逐场同状态诊断，不据此宣称模型修复或闭环因果。
