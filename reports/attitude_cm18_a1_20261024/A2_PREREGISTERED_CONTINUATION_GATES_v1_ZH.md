# A2 结果前继续门（Root）

在 A2 正式训练和闭环结果产生前冻结。这里是是否值得扩展的研发门，不是论文性能验收，不改变最终证据要求。

1. 源码、零形态、偏航不变性、共享梯度、跨语言一致性、初始化身份和因果时序检查全部通过，才放行一次正式训练。
2. 用 A1 完全相同的验证程序独立复算 A2 全48 VAL：场景等权 normalized vector RMSE 不超过 A1 的1.05倍，physical vector RMSE 不超过1.05倍，偏航轴 pooled RMSE 不超过1.05倍。physical vector RMSE 明确定义为每场 sqrt(mean_event(sum_axis(error²)))，再对48场等权平均；偏航 pooled 定义为全部48场事件偏航误差的 sqrt(mean(error_yaw²))，两模型使用相同事件集合。全部无非有限数。A1 数值必须由已封存数据/模型按同公式重算，而非混用 scene-average 与 pooled 数值。未通过即停止本候选闭环扩展，诊断标签/约束冲突，不加步数或调参。
3. 首个闭环固定 T3_C15_W14（已知失败之一，避免挑容易场）。完整安全、无非有限数，姿态SO3 RMSE不超过A1的1.10倍，位置Q不超过A1的1.10倍，姿态峰值不超过A1的1.20倍；同时核验全部事件身份/时序/输出，才放行其余固定11场。首场不是独立验证，选择目的明确为工程与失败机制筛查。
4. SCREEN12 全部安全且独立raw审计通过后，扩展DEV72必须同时满足：相对A1的12场等权平均SO3严格下降；位置Q均值不超过A1的1.02倍，且每一场Q不超过对应A1的1.10倍；两场C15_W14的SO3均严格下降且对各自RBF的正超额误差各恢复至少25%；相对RBF的SO3胜场至少8/12。若两场某项已优于RBF，超额恢复视为通过。阈值比较使用未舍入值，SO3严格比较容差1e-12 rad，Q容差1e-12 m。
5. 这组筛查不能证明整体优于RBF，不足以进入独立TEST。即使通过，完整DEV、所有失败、安全/饱和/三轴/阶段统计、公平运行耗时、理论适用域、消融与新封存独立测试仍需完成。

补充标签边界：现有 target_raw 是 alphaTrue-alphaVirtual，包含行为策略施加的实际补偿；不是天然等于理想逆映射动作。平面零偏导只能在固定行为补偿及其历史、状态、推力、形态、风，且分配保持同一无约束线性域时传递到该重建标签。旧RBF无当前参考加速度输入不等于数据集统计上不存在相关性。A2只检验这一物理先验是否有用，不宣称已证明所有数据标签严格满足独立性。

独立复核补充：仅改变参考角加速度，固定参考角/角速度、状态、形态、推力、风、RBF权重及历史时，旧RBF输入error/surface不变；同一时刻beta及逐轴clip后的c_old也固定。在分配不裁剪的同一线性域，才可由 d_old=E0+(I-G)c_old 得到行为标签偏航的条件零偏导。这不是观测数据统计独立性。A2的可归因对象是整个共享双视图训练/推理处理包，而非独立yaw头效应；双前向计算开销需实测，不能称成本与A1相同。
