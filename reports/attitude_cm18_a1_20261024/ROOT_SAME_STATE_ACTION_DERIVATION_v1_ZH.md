# 为什么离线残差预测好仍须核验新动作

本推导限定在同一记录状态、同一真实形态/形态速度、同一推力、无分配裁剪、电机瞬时执行的条件。它说明现有标签与新动作之间的关系，不是闭环稳定性证明，也没有改变本轮训练目标。

令C、C0分别为真实与固定名义4×4分配矩阵，S=[0,I3]选取力矩三行；J为真实惯量，J0为固定名义惯量。固定状态下保留真实陀螺、Jdot及风力矩。BS名义力矩为tau_BS，alpha_BS=J0^-1(tau_BS−omega×J0omega)。定义补偿的名义角加速度坐标c=J0^-1 tau_comp，单位rad/s²。因此请求为[T; tau_BS−J0 c]，平方转速为C0^-1乘该请求。

设不施加任何补偿时，相对alpha_BS的瞬时实际角加速度误差为E0。定义3×3动作映射

`M = J^-1 S C C0^-1 [zeros(1,3); J0]`。

由实际动力学中力矩线性项可得：

`E(c) = omegaDot(c)−alpha_BS = E0−M c`。

当前重标注定义是实际动力学与相同已补偿请求下名义动力学之差。旧动作对应c_old时，名义角加速度为alpha_BS−c_old，所以

`d_old = E(c_old)+c_old = E0+(I−M)c_old`。

新模型在相同记录上下文输出后，经beta及限幅形成c_new，则真实的瞬时跟踪角加速度误差为

`E(c_new) = d_old−(I−M)c_old−M c_new`。

特别地，仅在beta=1、无输出裁剪且模型精确预测d_old而取c_new=d_old时：

`E(c_new) = (I−M)(d_old−c_old)`。

这一般不等于零。只有在额外条件成立时（例如M=I，或旧补偿已恰好等于该残差），精确预测旧行为标签才直接给出零瞬时误差。若M可逆，当前局部无约束完全抵消动作是c*=M^-1 E0；这里不假设M总可逆，也不在部署中使用真值计算c*。

因此，预测误差、补偿量变化和实际跟踪误差必须分别报告。不能只看输出幅值或旧B/C5两条不同状态轨迹就判定适应/补偿有害。本轮依旧先训练已冻结候选，再在相同状态上计算旧/新请求经同一实际分配方程得到的误差，之后才观察闭环结果。

若任何请求/电机裁剪、非瞬时电机或其他执行器状态激活，上述线性M关系只作局部解释，必须回到实际分配与执行器代码重算；不得用无约束公式替代。记录真形态、J、Jdot、风只用于离线诊断，不能进入模型输入。旧B行为数据与部署C5的位置控制不同，也须另报输入/动作分布迁移；不能据这里的代数关系断言哪一个现有组件必然是失败根因。
