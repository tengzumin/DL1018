# C2前置鉴别：同状态补偿与部署可观测残差

启动依据：用户在C1完成且STOP后要求“继续吧，看看怎么改能够全改进”。本任务推进下一机制鉴别，不重开旧三轮，不更改C1或旧G06 STOP，不把继续研究解释为性能已通过。目标仍是总体、高频、无风共同改善，不能保证每场改善。

当前批准范围仅为离线读取、有限计算及新目录内的脚本/小表/报告。新训练、拟合第二c、修改部署控制器、MATLAB/Plant、72场与TEST均未在本阶段批准。机制证据充分后主审冻结唯一单因素任务书和明确预算，再作实施决定。

- 原始MAT/历史报告/受保护参考/模型/缓存不写入、不移动、不删除。只用PowerShell7，不结束或抢锁其他进程。CPU离线单线程，0 GPU、0 optimizer、0新Plant、0 TEST。

## 执行者A：同状态契约与全12场描述

独占reports/c2_same_state_worker_20261023/，新增上限100MiB。预先写清计算定义与采样/相位，完成后保留代码、输入身份和运行日志。

1. 对每条ON1自身状态/同一phi，计算原W0和实际在线W的raw输出，以及各自beta/clip后的应用量；先校验实际在线输出与日志一致。不能用B或ONC的另一条状态作为组件因果证明。
2. 优先由日志/已核物理方程重建Y=a_actual−a_req及实际全三轴PCF目标d=Y+r_f。核对时间戳，区分事件输出、后续保持应用、滤波/eta前后状态。旧TRAIN的M=diag(1,1,0)不能直接套到本批全三轴PCF。
3. 同状态分别报告对Y和d的拟合RMSE/偏置、应用量与raw的区别、逐轴及0–5/5–20s。若计算sc·(u−d)，只能称记录上的误差动力学交叉项，不称闭环收益或Lyapunov证明。输出总体、各任务、四风带和HF合并组；全12行保留。
4. 高频描述可用固定0–1/1–5/5–50Hz频带和同记录滞后相关，但必须核对事件频率、实际序列长度与有限窗口泄漏；不得搜索最佳滞后后宣称部署改善，不能把风组名称当实测频率。
5. 首先静态读schema和少量首末合法事件做恒等式检查；通过后一次全12统计。若原理/字段不支持，给出缺失证据，不盲目拟造物理目标。

## 执行者B：部署可观测性、因果时序与独立复核

独占reports/c2_observability_review_20261023/，新增上限50MiB，不改A或主审文件。

1. 从实际X14构造、位置BS、请求/滤波、Plant离散积分、事件scheduler及在线更新源码，列出每个量在部署何时可用。区分传感器可测/参考已知/内部可计算/真实物理oracle；无风组ID不得进入部署分支。
2. 检查用已测速度差分与已发请求重建上一transition残差的因果可行性；若积分并非Euler或观测有噪声，必须标为近似，报告时延和假设，不能称真实加速度。只能使用既有dt/时钟，不调滤波参数、不拟合新模型。
3. 对固定12条ON1做有限、冻结规则的只读误差核验，区分离线物理目标和因果近似；明确能否用于预测创新的目标、对齐和可用步。如果不具备部署输入，就否决相应修改方向。
4. 审核A的物理重建与解释边界，主审再独立复算。可查原始论文/作者仓库，不执行外部训练代码，不用文献替代本地证据。

## 主审决定门

必须交付全12覆盖、同状态比较、可观测量时间表、实现对应误差关系、已排除/未排除假设。只在这些证据支持唯一优先机制时，批准一个新候选的最小修改任务书；不同时改监督目标、网络、PCF和在线律。证据不足时仅安排能区分假设的最小离线检查。
