# 主动变形四旋翼：应用文献与公开代码补充核查

核查日期：2026-10-25  
范围：2023–2026 年主动变形/可变几何四旋翼中，形态执行器与飞行控制或轨迹规划存在实际耦合的工作；优先原始论文、DOI/arXiv 原文与作者论文直接链接的公开仓库。本文只记录论文报告的实验层级，不把论文描述等同于独立复现实验。未运行任何代码、仓库或实验。

## 结论先行

新增证据足以否定“形态变化与飞行控制/轨迹跟踪尚未耦合”“形态飞行的应用验证仍只有仿真”这类宽泛主张。2023 年已有形态参数自适应 NMPC 实飞；2024 年已有形态感知的全机碰撞约束规划及受限场景实飞；2025 年已有形态半径与位置轨迹联合优化及实飞；2026 年预印本进一步报告把关节角/角速度、形态执行器力矩和旋翼推力放进在线 MPC，并提供作者代码仓库。

对 C5 仍可保留的窄缺口是：在**给定形态指令/形态轨迹、固定姿态内环及指定位置环结构**的实验边界内，评估其学习式残差补偿对位置跟踪的增益，并与同一基线做有控制的对照。这个缺口属于特定控制器与坐标/训练设定的评估问题；不能据此主张首次研究主动变形飞行控制、形态-轨迹协同或受限空间实机应用，也不能推论出任务层收益或实机泛化。

## 新增工作

### Sun et al., 2023 — 变臂长四旋翼的设计与控制

[Science China Technological Sciences 原文 DOI](https://doi.org/10.1007/s11431-022-2370-9)

- **发表状态与验证层级：** 2023 年正式期刊论文。论文报告固定点悬停及轨迹跟踪实验；属于飞行控制实机验证，不是仅有仿真。
- **硬件 / 假设：** 曲柄滑块机构改变四臂长度。论文以切换线性参数变化模型处理不同形态，控制器在形态模式间切换；位置外环采用级联 PID。公开摘要未显示自主形态/路径规划或环境感知测试。
- **耦合判断：** 变臂形态与姿态模型/稳定控制相耦合，控制增益随形态模式处理；形态执行器命令仍是外部给定，未见形态变量与位置轨迹的联合优化。因此它证明形态变化下的实飞轨迹跟踪已有先例，但不等同于任务规划层的协同。
- **代码 / 数据边界：** 在本次核查的论文 DOI 页面范围内未找到研究专用代码仓库或原始飞行数据链接。可据论文重建控制思路，但不能直接取得作者实现并复现实验。

### Wu et al., 2023 — Ring-Rotor 可收缩环形四旋翼

[RA-L DOI](https://doi.org/10.1109/LRA.2023.3245499)；[arXiv 原文](https://arxiv.org/abs/2304.03514)

- **发表状态与验证层级：** RA-L 论文；arXiv 版本注明已于 2023 年获接收。报告真实飞行器穿越窄间隙、跟踪和全身抓取/搬运。
- **硬件 / 假设：** 一个舵机通过拉索、滑块与弹簧同步收缩机架，长度和宽度同时变化。平台含 Kakute H7、Jetson Xavier NX；NMPC 以 IMU 与动捕反馈、100 Hz 更新。穿越实验在受控实验室环境中进行，姿态/位置状态由动捕辅助，而非仅凭机载感知自主建图。
- **耦合判断：** NMPC 根据变化中的动力学参数（包括惯量、控制分配等）调整旋翼推力，因而飞控实际适应形态变化；舵机另有比例长度控制器，形态参考与飞行轨迹参考分开提供。论文没有把形态变化时刻/路线作为同一优化问题中的联合决策变量。它证明了形态适应控制和应用实飞，但不构成联合形态规划的证据。
- **代码 / 数据边界：** 原文使用 ACADO 与 qpOASES 求解，但论文未链接完整研究代码、机械 CAD 或原始数据；这些通用依赖不等于论文实现可直接复现。

### Cui et al., 2024 — 受限场景中的形态四旋翼规划与控制

[RA-L DOI](https://doi.org/10.1109/LRA.2024.3396109)；[arXiv 原文](https://arxiv.org/abs/2312.07075)

- **发表状态与验证层级：** 2023 年提交预印本，2024 年正式发表于 RA-L。包含 Gazebo 简化 SDF 仿真和真实平台飞行实验。
- **硬件 / 假设：** 四个舵机折转四臂；实机包含 Jetson TX2、CUAV Nara+、RealSense D435，机体约 48×40×10 cm。论文报告圆周轨迹持续变形跟踪、40 cm 圆环穿越、40 cm 方形墙洞及 45 cm 内径、190 cm 长管道等实飞。对比穿墙洞与飞越高墙时，文中按电池消耗报告该设置下变形穿越约节省三分之一能量。
- **耦合判断：** 规划器构造随舵机角度改变的全机几何/安全约束，并从规划结果给舵机角参考，由 PD 伺服控制；非线性姿态控制同时在线更新惯量、质心和推力系数。它是“形态感知碰撞规划 + 形态适应飞控”的实机协同，但原文的 MINCO 优化轨迹变量主要是位置轨迹，形态角通过规划/几何约束给出；不能表述为位置与形态自由度的完全联合最优控制。
- **代码 / 数据边界：** arXiv 原文可读，论文未链接本研究的完整代码或原始飞行数据。文中依赖公开规划/定位工具不代表整套软件和实验数据已公开。

### Wu et al., 2025 — Shape-Adaptive Planning and Control

[IROS 2025 DOI](https://doi.org/10.1109/IROS60139.2025.11245898)；[arXiv 原文](https://arxiv.org/abs/2505.15010)

- **发表状态与验证层级：** IROS 2025 正式会议论文；论文同时报告仿真和真实平台实验。
- **硬件 / 假设：** 延续 Ring-Rotor 环形全身抓取平台，单舵机拉索机构同时改变两个平面尺寸；论文报告最大尺寸 42.2×42.2 cm、最大缩小约 37.8%。实机导航使用雷达点云构建环境地图，并融合 NOKOV 动捕与 IMU 获取状态；属于受控环境内实机验证。能耗对比由论文给出的功率模型和规划仿真计算，不能当作实机能耗测量。
- **耦合判断：** 这是本次核查中清晰的形态-位置联合规划先例：kinodynamic A* 状态包含位置/速度与可变半径，后端连续轨迹以 \(\sigma(t)=[p(t),r(t)]\) 同时表示质心运动和形态；舵机跟踪形态命令，飞控按形态更新控制分配并补偿力/力矩扰动。论文报告穿越多个窄口（含五次连续变形）、小于 5 cm 平均控制误差、160 g 物体全身抓取搬运，以及图 8 字形跟踪 RMSE 0.0352 m。该工作已覆盖形态与任务轨迹联合规划和实机验证。
- **代码 / 数据边界：** 本次核查的论文/arXiv 页面未找到作者专用代码仓库或原始数据集链接。论文可用于理解算法与实验设定，但没有公开软件/数据包可直接复现实验。

### Modi et al., 2026 — 受限感知下的超窄通道 MPC

[arXiv 预印本](https://arxiv.org/abs/2605.15999)；[论文直接链接的作者 GitHub 仓库](https://github.com/harshjmodi1996/morphocopter_mpc)

- **发表状态与验证层级：** 截至 2026-10-25，核查到的是 2026-05-15 提交的 arXiv 预印本，未发现正式发表版本。论文正文报告 Gazebo/PX4/虚拟 LiDAR 仿真，以及 MorphoCopter 加装 2D LiDAR 的实机实验：穿过 0.33 m 间隙和最窄 0.38 m 的杂乱障碍通道。需保留一项来源内部不一致：摘要称框架仍在实现到变形四旋翼上，但正文实验章节和结论明确写出 MorphoCopter 硬件实验；因此“实机验证”应表述为作者正文报告，且该预印本摘要/正文不一致。
- **硬件 / 假设：** MorphoCopter 可折叠关节，机载 2D LiDAR 感知。高层 BIT* 给出一般路径参考；在线 acados NMPC 根据局部障碍更新轨迹、偏航和关节角，低层 PID 以 120 Hz 跟踪（MPC 10 Hz）。
- **耦合判断：** 关节角与角速度直接进入 MPC 状态，关节力矩与四个旋翼推力进入控制输入；关节角参考依最近障碍几何计算，障碍成本、飞行轨迹偏差和控制输入成本共同优化。狭窄杂乱实验明确报告 MPC 同时调整轨迹、偏航和关节角。这是直接的在线形态-轨迹/控制联合优化证据。
- **代码 / 数据边界：** 作者论文直接链接公开 [MIT 仓库](https://github.com/harshjmodi1996/morphocopter_mpc)，README列出 ROS 2 Humble、Acados、Gazebo Garden 7.9、PX4-Autopilot 1.15.2，并提供 MPC ROS 节点、消息、Gazebo 模型和运行说明。因此它比仅有控制方程或伪代码更可直接复现，尤其是软件仿真部分；硬件复现仍需要 MorphoCopter 机体、LiDAR、相应飞控/传感器与搭建环境。该仓库未见单独发布原始飞行数据集。本次只核对仓库说明，没有克隆或运行。

## 与既有 literature_review_v1 去重及对 C5 的影响

本报告不重复展开既有审阅中的 Foldable Drone (2019)、Bai (2019)、Fabris (2021) 和 Qin (2025)。新增工作把既有“学习残差补偿在给定形态/固定外环设定下的定位控制研究”放到更完整的应用脉络中：

1. **应用主张应收窄。** 不宜写成主动形态飞行的实际应用、穿越受限空间或变形中的轨迹跟踪缺少实证；2023–2025 年已有多个实机例子。也不能把形态-轨迹协同当成空白，2025/2026 年已有联合形态状态规划/在线 MPC。
2. **控制器层贡献仍可明确。** 可以主张检验特定学习式残差（例如 TCN）对既定位置环在形态变化过程中的跟踪误差影响，并报告相对同一控制器基线的对照。应说明形态命令预先给定、姿态内环沿用现有方法、验证环境是仿真还是实机；避免把它包装成形态规划、任务收益或完整自主飞行方案。
3. **窄缺口及证据边界。** 本轮未发现一项与 C5 完全同设定的工作：同一位置环坐标/残差定义、相同形态指令和固定内环下的学习补偿因果对照。但这是有边界的“具体控制器组合/评价协议”缺口，不代表研究领域整体没有形态耦合控制。若 C5 仍只在单一仿真 Plant、理想或预设形态执行下测试，结论应限定在该 Plant 与设定，不能外推到真实执行器、未知环境、实机安全或任务能效。
