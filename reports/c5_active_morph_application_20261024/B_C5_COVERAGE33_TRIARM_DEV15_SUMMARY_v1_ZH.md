# B、C5+RBF 与 C5+CM18：15 场 DEV 三臂汇总

## 范围与口径

本报告汇总现有 15 份 `C5_COVERAGE33_AUDIT_v1.json`、binding v3 与已冻结结果报告中的场景指标。15 场均为 DEV 开发留出场景；每场 20,000 次 transitions。宏平均是逐场 RMSE 的等权算术平均，Q 单位为 m，SO(3) 单位为 rad。胜/负按逐场 RMSE 严格较低/较高计，平局单独计数。

三臂定义如下：

- **B**：原始 B 完整系统级参考，审计字段为 `original_B_overall_reference`，包含位置 RBF 环与在线姿态 RBF 环。
- **C5+RBF**：C5 位置环配原始在线姿态 RBF，审计字段为 `matched_C5_position_original_RBF`。
- **C5+CM18**：C5 位置环配 CM18 姿态模型，审计字段为 `candidate_C5_COVERAGE33`。

主比较是 **C5+RBF 对 C5+CM18 的姿态替换比较**。B 是完整系统参考；B 与 C5+RBF 的差异同时包含位置环差异，不能用 B 对候选的差值解释姿态环单因素因果。

## 判定与证据边界

预登记的 C5_COVERAGE33 扩展门要求 15 场全部完整安全，候选的 ALL Q 与 SO(3) 宏平均严格低于 C5+RBF，并且 W09–W14 两项均不劣于该基线。完整性与安全检查通过；但 ALL Q 为 0.014685544 对 0.010330890、ALL SO(3) 为 0.043670033 对 0.015244282；W09–W14 Q 为 0.015063655 对 0.010751719、SO(3) 为 0.046978685 对 0.017204128。四项门槛均失败。现有结果报告据此停止此路线的扩展，不解封 TEST。

原始 B raw 内容绑定已核对：binding v3 的 15 个 `b_raw_sha256` 均与对应 audit 的 `original_b_raw_sha256` 相符，磁盘文件重算 SHA-256 也 15/15 相符；每份 audit 声明的 binding SHA 与 binding v3 文件 SHA 相符。binding v3 文件 SHA-256 为 `87ac859a29488d66f87330a7f0060183fb9a3e07178244677db28cbd8a527ee8`。其中 6 场使用 `_ACC_FIX_V1` 历史场景 ID 别名。binding 绑定了 B raw 内容和场景 ID，但没有绑定对应 B 的 `run_start.mat`、运行源码、cfg/opts 身份；因此能确认原始输入记录的内容，不能据此追溯历史 B 运行的完整生产身份。

本表是 15 场 DEV 闭环结果，不是独立 TEST 结论。B24/C5_24 属于离线姿态模型配对训练与缓存诊断分支；对应训练收据记录了训练步数、缓存/目标来源，但 `Plant_calls=0`。其离线缓存误差或胜负不能当作闭环胜负，也不计入本报告三臂结果。
