# 姿态新输入：有限离线信息对照任务书 v1

主审核批准准备以下诊断脚本；源码审核通过后才执行拟合。不启动正式神经网络训练、GPU 作业、Plant 或新航次。不读 C5 TEST48，不修改历史工程。

## 目的与数据

检验命令累计状态、当前伸缩速率和过去动作是否增加旧 B 行为轨迹上残差的预测信息。这不是闭环性能试验，不宣称输入充分或因果贡献。

TRAIN：按场景 ID 字典序，在本地 TRAIN 的每个 `(task, Cxx)` 组合中取第一场，共 3×16=48 场；只用事件行 0,5,10,... 拟合。VAL：全部既有 48 场，保留每个事件。先按上述无成绩规则生成精确场景清单并封存 SHA，再读数值。不得临时更换缺失或失败场。

输入身份：每场现有 `B.h5`、匹配 `raw_run.mat` 和 `run_start.mat` 实际哈希；固定当前特征重建源码及本任务书。旧运行精确源码身份缺口继续披露。H5 标签仅用于这次离线信息探查；正式新数据导出还需分层物理核验。

## 输入、标签与对照

共同当前上下文 B7：机体系角速度 3、补偿前名义机体系角加速度 3、请求推力/质量 1。

额外信号：当前已发形变速率命令 u4；过去命令的累计 signed duration z4（初值零，逐 1 ms 更新，事件 k 仅用 i<k 的命令）；上一完整事件区间请求力矩均值 a3（按全部已完成 1 ms 请求加权，不能用上个事件单点替代）。

固定五组：

| ID | 输入 | 标量数 |
|---|---|---:|
| G0 | B7 | 7 |
| G1 | B7 + u4 | 11 |
| G2 | B7 + z4 | 11 |
| G3 | B7 + z4 + u4 | 15 |
| G4 | B7 + z4 + u4 + a3 | 18 |

另列零输出参考，不拟合第六个模型。z 是四维显式内部状态，不是真实构型测量；网络同时读取 u 和 z 时是八个形态相关标量。

alpha_BS 从 raw 记录的名义力矩、当前 omega 和固定名义 J0 重建，包含名义 Jdot 项；J0 必须从 cfg 对应的共同物理定义得到并核查各场配置一致。可将已有 H5 的物理 alpha 列作数值交叉检查，不能仅按旧 X29 列号复制而不核验定义。omega、推力、命令、z、动作上下文均从 raw 重建，且按实际事件索引对齐。若有配置、时间或字段不一致，停止并报告，不静默换样本。

标签固定 H5 `target_raw` 的事件瞬时机体系角加速度残差（rad/s²），不用旧 clip 标签，也不以区间角速度差代替。目标是旧行为条件残差，不是无动作依赖的外生风。

## 唯一估计器与资源

五组均采用同一个二次多项式 Ridge：原输入的一次项及所有 i<=j 的二次乘积，加一个截距；原输入用拟合 TRAIN 样本的均值/标准差标准化，sigma 下界 1e-6，不剪裁；目标按相同 TRAIN 样本的逐轴 RMS 缩放，下界 1e-6。

求解 `(X'X/N + 1e-3 D) W = X'Y/N`，其中截距项的 D=0，其余 D=1。不调正则、不扫种子、不更换估计器。最多 5 次闭式监督拟合、0 optimizer steps。顺序拟合、仅一个 CPU 作业，BLAS 线程 1，预计产物不超过 256 MiB；内存不足时按场流式累计矩阵，不扩大作业。

## 输出与审核

保存准确清单、全部实际输入哈希、源码哈希、命令、退出码、耗时和拟合调用计数。记录归一化数组和回归系数，便于独立复算；这些是诊断模型，不注册部署模型。

逐场及分组报告三轴物理 RMSE、按 TRAIN 逐轴尺度归一化的向量 RMSE、峰值预测误差；分组包含任务、Cxx、风组、原 phase_code，特别报告 C00/PRE/RECOVERY 的伪补偿幅度。组汇总用场景等权；相位内缺少样本的场景列为空，不当作零误差。

有限 VAL 是开发数据，允许根据预登记五组对照形成下一步输入判断，必须披露选择过程；它不是独立测试。若所有组都差，只能说明该估计器/数据下没有证据，不能宣称相应信号无用。离线胜出也不等于闭环胜出。

实施文件只写新子目录 `reports/attitude_redesign_20261024/offline_input_probe_v1`。先交脚本和封存清单给主审核，不先执行拟合。C5 位置冻结、C7 暂停，旧 KAN29 路线保持取消。
