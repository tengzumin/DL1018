VAL 的 G2 将物理向量 RMSE 从 ZERO 的 12.0501 降至 3.4625，但归一化误差从 1.8607 升至 3.3386；且其 yaw 轴 RMSE 为 1.6615，高于 ZERO 的 0.5574。G3 的物理/归一化误差分别为 3.5796/3.8323，yaw 为 1.9112。因此仅增加历史命令积分 z 不足以形成一致的三轴改善。G4 的三轴 RMSE 均低于 ZERO，物理/归一化误差为 0.6855/0.3410，但仍是目标预测拟合结果，不能外推为姿态闭环收益。

C00、PRE、RECOVERY 的目标 RMS 均约为 `3.5e-14` rad/s²，而 G4 输出 RMS 分别为 0.6097、0.4209、0.4722 rad/s²；G0–G3 的输出也非零。此处记录的是近零目标下的预测输出幅度，提示后续候选需处理无形变阶段残留；它本身不等价于实际施加补偿，也不证明其闭环危害。

下一步需由独立复算完成后再决定。当前结果支持进一步验证输入与输出门控设计，不能据此冻结部署架构、宣称稳定性或把离线拟合改善写成闭环因果收益。
