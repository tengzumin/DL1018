# 有限路径投影界：范数容差与浮点实施补充

冻结原命题及首个合成检查保留原SHA。它们按实数更新和单位特征写出。实际helper用浮点运算，并允许单位范数检查有容差，因此不能把理想(B)在浮点raw上逐位当成无余项恒等式。

**非精确单位范数。** 给定实数上界 `L >= max_q ||phi_q||_2`，(B)本身不依赖单位范数，仍成立；(H)改为

`历史原始输出残差平方和 <= 2P + 2 L^2 J`，

故(F-bound)首项改为 `sqrt(20(P+L^2 J))`。helper的norm容差为1e−10；严格数值代入还须计入norm运算本身的舍入并检查所选向上包络L，不能从打印的1.000000断言实数范数恰好为1。原实数单位范数命题与有理数合成检查对应L=1，没有改变。

同理，原命题中明确假设理想单位特征的可选粗界，在一般L且`||y||≤Y`时应写为 `||b_q||≤0.12 L S+0.00002 R` 和 `||G_q||≤rho(R L^2+L Y)+0.12 L S+0.00002 R`；R与S沿用原定义。不将原单位范数粗界直接用于容差版机器数值。

**投影后数值残差。** 原raw没有存完整未投影candidate，不假称可以直接读取它。用原命题的实数G定义

`Z_q = Pi_C(W_q-G_q)`，`delta_q = W_(q+1)^actual - Z_q`，

则(B)右侧在其投影残差取 `R_q^ideal=Z_q-(W_q-G_q)` 后，加上

`D_num,q = 2<delta_q,Z_q-U>_F + ||delta_q||_F^2`。

证明是展开 `||Z_q+delta_q-U||^2`，再用原投影距离式；符号为加号。若只知 `||delta_q||_F <= eta_q`，因Z与U都在盒内且R=60√99，可保守加上 `4R eta_q+eta_q^2`。该形式不要求重建未记录的MATLAB candidate，也不要求把实际浮点残差设为零。

这里delta若用普通浮点重算得到，只是数值一致性检查；声称严格机器区间证书还需将G重算和范数舍入向外包络，或给定明确eta假设。当前18个Fraction合成边界检查只验证理想实数公式，不是实际DEV轨迹的浮点区间认证。本补件不提供尚未实施的数值误差认证，更不升级为先验Plant误差或稳定性保证。
