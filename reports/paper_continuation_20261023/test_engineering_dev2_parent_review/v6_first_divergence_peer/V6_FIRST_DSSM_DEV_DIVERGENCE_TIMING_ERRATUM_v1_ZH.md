# v6 DSSM 分叉时刻勘误

本勘误只修正 v1 对 **v6 与误选 legacy DSSM raw** 的状态阈值时刻解释；保留 v1/v2 原文件与 SHA，不改变启动前模型、同一状态下 `t=0.320 s` 首次推理、头输出/PCF 链条及全程最大差值结论。

根对 `t=0.321 s` 的 12 维 state 绝对差复核为：

`[4.95e-14, 3.675e-13, 1.25055e-10, 1.469e-10, 7.453e-10, 2.5011e-7, 5.839e-9, 2.9222e-8, 3.806e-13, 1.1678e-5, 5.8444e-5, 1.6915e-7]`。

因此任一 state 维以及任一位置维首次超过 `1e-12 m` 都在 **0.321 s**。v1 中 **0.323 s** 的 `2.15e-12 m` 只表示 X-position 分量首次越阈时刻；原脚本 `np.argwhere` 返回 `[0,323]` 是按所检查的 X 字段定位，不能称作整体 state/position 的最早越阈时刻。首个非零 state 差仍在 0.321 s；全程最大差仍为 `0.13140362151790552 m`。

这项修正不涉及真正 corrected DSSM 历史 run `r002`：根此前核验 v6 DSSM 与 corrected r002 的 377 个非计时数值数组完全一致。模型身份结论应以 corrected r002 为历史基准；这里的 state 交叉只说明误选 legacy raw 的差异。

机器可读数值与保留文件 SHA 见同目录 `V6_FIRST_DSSM_DEV_DIVERGENCE_TIMING_ERRATUM_v1.json`。本勘误只使用根已提供的独立数值复核，没有重读 raw、TEST 或重新执行仿真。
