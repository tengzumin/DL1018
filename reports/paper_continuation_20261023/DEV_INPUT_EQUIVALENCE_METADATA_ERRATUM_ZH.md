# DEV输入等价检查：生成器注记字段勘误

主审在任何新MATLAB启动前读取两个GET分支及首个历史B原始MAT的scene字段，发现一个确定的非物理schema差异。旧scene字段为arms、environment_wind_I、initial_state、reference、scene_id、time；当前生成器GET另在scene与metadata上增加reference_contract_id。两者construct_scene与make_reference正文相同，当前额外字段是生成契约注记，不参与动力学输入。

原CODE ONLY任务书仅允许ACC_FIX_V1别名规范化；这里补充允许的唯一注记处理：逐场记录当前reference_contract_id原值，并严格核对锁定当前生成器reference_contract_id函数返回的固定常量；旧生成器/旧B缺少此字段须明确记录。仅在用于等价比较的临时struct中去掉已严格核对的这个注记字段。其余字段不删除、不忽略；scene ID、command及离散标识仍严格相等，所有物理数组仍同形、有限，逐字段报告原单位最大绝对差与bit相等标志，原1e-12阈值不变。

这不是根据运行失败放宽数值判据，也未运行Plant或生成TEST数组。当前schema差异已由源码和实际历史MAT字段共同确认；完整72场物理等价仍需实际无Plant运行验证。本勘误不授权任何执行模式。
