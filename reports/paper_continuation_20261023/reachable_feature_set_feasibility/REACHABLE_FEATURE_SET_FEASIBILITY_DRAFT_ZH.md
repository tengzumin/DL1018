# DSSM14 可达特征集合：静态可行性诊断

日期：2026-10-23。范围仅为冻结编码器与模型参数的只读检查；未读取 raw/TEST，未启动 MATLAB/Plant，未改模型。

## 结论

**可以**从已部署 DSSM14 编码器构造严格小于整个 33 维单位球面的特征外包集。它保留了固定正偏置坐标及隐藏坐标间的比例约束。**但现有低成本外包集不足以证明输出不裁剪**：对锁定的初始输出权重，外包集上的数值支持上界有两列仍超过 3。这不证明实际可达特征会触发裁剪，也不排除更精确的编码器可达域会给出更紧上界。

## 冻结对象与源码依据

锁文件 `experiments/position_axis_coordinate_c5_dev72_20261023/C5_DEV72_INPUT_LOCK_v3.json` 的 SHA-256 为 `82024c01276cc4bfbd9b7772cf5332dee3fdfcbed422969589b68f1c90ed2d75`。它绑定实际运行时编码器 `position_stage1_model_forward_v2.m`，SHA-256 `dc803aa102c49d67dd687ae941f8a60bb0c465f74fd01e5ae93ad1ea1a293676`，以及 DSSM14 模型 MAT，SHA-256 `6f3628b10540c617496b2a20f249c4319af79c1a02d5945f1f91f0aead9c9b6e`。MAT 检查只载入 `model` 变量。

在冻结编码器中，归一化是 `(window-mu)./max(sigma,1e-4)`（第 5–6 行），只断言结果有限（第 12 行），**DSSM 分支没有输入 clamp**。第 54–61 行把状态初始化为零，以 `drive=tanh(W*x+b)` 驱动，并按 `state=alpha.*state+(1-alpha).*drive` 更新，再以 `h=tanh(project_W*state+project_b)` 投影。第 136 行输出 `phi=[h;1]/sqrt(1+sum(h.^2))`。

固定模型的 `ssm_tau` 有限且范围为 `[0.00530062, 0.95874685]`，故 `alpha=exp(-0.01/tau)` 范围为 `[0.15159071, 0.98962392]`，各坐标均在 `(0,1)`。每个 drive 在 `[-1,1]`；从零开始的逐坐标凸组合使 state 保持在 `[-1,1]^32`。投影 tanh 因而给出 `h∈[-1,1]^32`。这不依赖输入幅值，但仅要求每个传入窗口有限。参数矩阵、偏置和归一化数组均有限；`input_W` 数值秩为 14，`project_W` 数值秩为 32。直接以 state 盒传播到 project 层，最宽的 tanh 坐标界已达约 `0.99994235`，所以这一层的简单区间收紧很有限。

## 得到的严格特征外包集

令 `h∈[-1,1]^32`，则

`phi=(h,1)/sqrt(1+||h||^2)`，`||phi||2=1`，`phi[33]≥1/sqrt(33)≈0.17407766`，且 `|phi[i]|≤phi[33]`（i=1,…,32）。

因此 `phi` 属于单位球面上的闭锥帽

`C∩S^32`，其中 `C={(z,t): t≥||z||∞, t≥0}`。

该集合严格小于整球面：它排除了末坐标为负及末坐标小于 `1/sqrt(33)` 的方向。实际理想实数运算中 tanh 值落在开区间；报告采用闭盒，是对浮点实现也安全的外包。由此**不能**得到有用的时间变化率界；不受 clamp 的每帧输入也未被约束为具有某个物理数据分布。

## 对“不裁剪域证明”的最低成本检查

对固定初始输出矩阵的每一列 `w`，在上述锥帽上的线性输出绝对支持可写成 `max(||Π_C(w)||2, ||Π_C(-w)||2)`。按该式作双精度数值投影检查，三列上界约为 `3.98969、3.94158、1.45463`。前两列高于 3，故仅以 `h∈[-1,1]^32` 得到的结构性约束，仍不能给出初始输出始终小于 3 的证书。它只是外包集的上界；**不得解读成真实编码器可达轨迹会裁剪**。这组数值投影尚非区间算术证书；若要将其作为正式证书，需要以向外舍入或精确有理边界核验。

## 继续的最小计算与限制

若值得继续，最小的实质步骤是为冻结 32 帧编码器构造可验证的 state/feature 可达外包，再对固定 `W0` 做全局支持上界，并检查是否能严格低于实际输出限幅。源码本身没有输入 clamp；可从每帧驱动集合 `tanh(Wx+b), x∈R^14` 出发，经 32 次逐坐标递推、project、tanh 和归一化传播外包。由于 `input_W` 数值秩 14 且 `project_W` 数值秩 32，不能假定这会自动带来大幅收紧。至少需要一个可验证的区间/凸外包和有证书的全局优化；当前报告不做该搜索。

即使 `W0` 的固定支持成功低于限幅，也只解决初始头。部署中 `W_q` 会更新；完整无裁剪证明还需证明特征与自适应权重的联合可达域支持界，或另有闭环不变域。这个特征分析不补齐延迟标签、`r_f`、采样余项和物理输入的先验界，也不推出 Plant 稳定性。基于现有证据，结论是：**存在严格子集，值得做一次有界的可达域支持可行性检查；尚不足以替代部署裁剪条件或闭环误差界。**
