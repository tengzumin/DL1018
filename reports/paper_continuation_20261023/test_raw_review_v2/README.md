# TEST48 mixed v3/v4 raw reviewer

`audit_test48_raw_v2.py` is a post-run reader for the mixed package: the 48 B baseline flights are reused from v3, and the other five fixed method blocks come from v4. It preserves the v1 scorer and raw audits while applying version-specific identity checks to each side of the package.

The reviewer requires the root-approved v4 run release, exact v3 frozen input package, the reused B48 v3 OS0 receipt, and five v4 natural OS0 receipts in method order before opening any raw MAT or calling the scorer. It also verifies the prior v3 DSSM OS1 startup separately: one failed pre-Plant scene, zero Plant calls, no raw, and no first-Plant marker. That historical startup remains outside the v4 success batch.

The v4 lineage check requires B, C5, all model references, cfg/opts snapshots, and shared sources to match v3. For DSSM and KAN it accepts exactly one additional locked source each: `position_filter_realization_pcf_step_v3_5.m`, with the frozen SHA recorded in the script. The reviewer checks the fixed VAL engineering receipts and numeric comparison results without reading their MAT outputs. It records those process intervals, the v3 failure interval, the five v4 method intervals, and gaps between sequential processes. The report states that the old corrected raw files did not record a historical MATLAB `which` SHA; the engineering replay bridges behavior, not retrospective source identity.

For B, the wrapper calls the frozen v1 record, run-start, and MATLAB binding checks. For the five new blocks it checks the v4 release, batch/body agreement, all 48 artifact paths and SHA values per method, status records, run identities, frozen snapshots, exact model/normalizer identities, `which` bindings, and shared scene identity. It then reuses the frozen v1 scoring, actuator-channel, 20,000-transition timer, native-readiness, corrected initial-W0 and C5/ablation event auditors. The accepted output keeps the existing statistics schema (`PASS_TEST48_RAW_IDENTITIES_PHYSICS_ALL_METHODS`, `TEST_accessed=true`, 288 unique rows). That audit status does not decide the paper performance gate.
