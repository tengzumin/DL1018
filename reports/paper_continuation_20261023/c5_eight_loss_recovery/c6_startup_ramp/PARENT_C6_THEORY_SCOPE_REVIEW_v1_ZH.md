# C6 理论适配审核：加权路径不等式不等于收益保证

根已直接读取冻结 C6 MATLAB helper，确认预测更新系数从 rho 改为 a_q=rho beta_q，其他 tracking/leak/单次盒投影公式不变。q>=1 时 beta_q>0，最小值为 331/1800；q=0 无历史标签，不能补造预测项。beta 是已有绝对仿真时钟，并非新调出的时间阈值。

令 psi_q=phi_(q-1)，ell_q(W)=||W^T psi_q-y_(q-1)||²/2，g_q=psi_q(W_q^T psi_q-y_(q-1))^T，b_q=0.12 beta_q phi_q s_eff,q^T+0.00002 W_q，G_q=a_q g_q+b_q，D_q=||W_q-U||_F²。U 必须在运行前固定于盒 C。

对于精确算术，投影变分性质和二次损失恒等式直接给出：

2 sum_q a_q[ell_q(W_q)-ell_q(U)] + sum_q a_q||psi_q^T(W_q-U)||²
<= D_1-D_(m+1)+sum_q||G_q||²-2sum_q<b_q,W_q-U>-sum_q||R_q||²，

其中 R_q=Pi_C(W_q-G_q)-(W_q-G_q)。实际浮点实现需保留与 C5 一样的 delta_q 校正项 2<delta_q,Z_q-U>+||delta_q||²；不能假定全部为零。因 a_q 随时间变，左边是加权损失差，不能不加说明换成 C5 的常系数无权求和。尤其 ell_q(W_q)-ell_q(U) 可正可负，不能用 a_min 简单逐项替代 a_q 后保持不等式。

历史实际输出仍使用 W_(q-1)，因此历史残差与当前权重拟合之间的权重漂移项 J 不能删除；输出 ramp、clip、PCF 坐标差和采样余项同样保留。beta=1 以后，只有在同一 W/phi/s/标签上两公式相同；此前权重轨迹差会继续影响闭环，不能称后期行为完全不变。

根独立完成600组随机代数检查，69组投影激活，包含大标签触盒情况；最大二次恒等式浮点残差2.55e-10，投影不等式最小数值松弛-1.22e-10（舍入量级）。完整结果在 PARENT_C6_WEIGHTED_BOUND_SYNTHETIC_v1.json。这只检验推导的数值一致性，不证明闭环稳定、误差收敛或 C6 优于 C5/B。

决定：理论形式可按上述权重适配，但 C6 方法贡献及收益目前均未成立。必须先看预登记固定12场的闭环反证门。不得以减小预测梯度、投影有界、训练损失或本合成检查作为论文达标证据；也不得直接把 C5 已完成的路径数值证书移植给 C6。若进入 DEV72，应重新核验全部事件/物理桥和对应路径项，并由未撰写本推导的执行者复核。
